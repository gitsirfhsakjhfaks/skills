# HTML 补救与溯源规范

只在用户同意制作或已明确要求 HTML 时读取。本规范服务于当前质询中发现的具体理解偏差，不要求为每次问答生成页面。

## 从偏差确定交互

先从实际问答中确定：用户混淆或遗漏了哪条关系，什么操作能让用户观察到区别，以及观察后应能解释什么。围绕最重要的一处偏差组织页面，必要时容纳直接相关的少数偏差。

选择能揭示该关系的交互，例如：

| 偏差 | 合适的交互 |
| --- | --- |
| 把相关当因果、遗漏中间机制 | 切换前提或干预，观察因果链上哪些环节变化。 |
| 不理解变量如何影响结果 | 调整有意义的变量，同时呈现结果及变化原因。 |
| 忽略适用条件 | 切换条件，比较成立、失效或信息不足的情形。 |
| 混淆两种方案的取舍 | 固定目标，切换约束，比较结果与代价。 |

这些是候选形式，不是每页必备部件。数学关系必须有依据；原材料只有定性信息时，用明确标为示意的状态变化，不编造精确公式或漂亮数值。真实数据、教学假设和示意模型要能区分。

## 单文件、离线复用

- 生成一个 UTF-8 的 `.html` 文件，内嵌 CSS、JavaScript、必要 SVG 和上下文摘录。核心说明、交互及溯源在断网和通过 `file://` 打开时均应可用。
- 不依赖 CDN、外部字体、在线接口、构建工具或后端。外部来源链接可供查阅，但页面不能依靠它们才能运行。不要擅自发布或托管页面。
- 使用正常浏览器输入控件，提供可见标签、状态反馈和重置。改变参数后，相关图形、输出与解释同步更新；纯切换文字若不能揭示偏差中的关系，就不算有效演示。
- 让用户可以重复操作并比较结果。对超出模型范围的输入明确提示边界，不给伪精确结论。
- 若加入练习，先让用户预测或作答，再由用户操作揭示解释。只在存在可靠规则时自动判分；无后端的页面不能假装理解和评判开放文本。
- 记录保存不是默认必需功能。若确需保存页面中的新练习记录，提供明确的本地下载；不能仅依赖 `file://` 下行为不一致的浏览器本地存储。默认不向外传输任何材料或作答。

## 把溯源保存在页面内

设置易于找到的“材料与诊断依据”区域，可折叠但离线可读。保留足够理解本次偏差的上下文，不机械复制整段聊天；遵守来源摘录限制。

至少覆盖以下信息；没有的信息明确写“未提供”或“待验证”，不要补造：

1. **页面身份**：主题、文件版本、生成时间及已知时区。使用实际时间；同一主题后续修订保留版本区别。
2. **原始材料**：来自哪段 AI 回答、文档或其他材料；保存相关原文摘录，并提供实际可用的标题、章节、路径或来源链接。没有可持久引用的聊天链接时，注明“当前对话中的相关回答”，以摘录定位，不虚构消息 ID 或链接。
3. **理解证据**：导致本次诊断的实际题目和用户回答。原文与概述明确区分，不改写成更严重的错误；回答过长时保留关键摘录并说明省略范围。
4. **诊断与纠正**：具体缺失或错误的关系、纠正说明，以及它依据哪条材料。若结论需要外部验证，记录实际查证来源；未核实的地方保留不确定性。补充的例子与假设明确标注为教学内容。
5. **交互映射**：每个关键变量、条件、输出代表什么；模型采用哪些假设，能解释什么、哪些情况超出范围。将页面中的演示与被纠正的关系对应起来。
6. **复测状态**：区分已观察到的回答证据与待完成的复测。页面内后续示范题标为“新练习”，不要混入原始问答，也不提前标记为通过。

将用户原文和来源摘录作为文本安全嵌入，正确转义 HTML 和脚本上下文；不要让材料中的标签或脚本成为可执行代码。

## 保存、验证与交付

- 保存到当前环境约定的用户交付目录；没有约定时使用用户指定目录或工作区的 `outputs/`。建议文件名为 `inquiry-YYYYMMDD-topic-v1.html`，主题用简短、兼容文件系统的名称。
- 同主题已有文件时保留原版，新增版本并记录此次变化；用户明确要求覆盖时依其要求执行。不要把用户机器的绝对路径写成页面运行依赖。
- 在可用浏览器中实际打开保存的文件，检查核心交互、初始状态、边界与重置，核对演示结果是否符合纠正依据，并确认源码没有运行所需的外部依赖。验证保存后的文件，而不是只看生成代码。
- 若环境只能提供本地 HTTP 预览，要说明尚未验证直接通过 `file://` 打开；若没有浏览器能力，至少检查源码、依赖和逻辑，并如实说明未完成的验证。不要把静态检查表述成完整交互验证。
- 提供 HTML 文件的可点击链接，并用一句话说明该页纠正的偏差及操作方法。用户需要查看时用环境现有能力打开。不要用截图或预览地址替代独立文件交付。
- 页面交付时说明看完后可返回复测；用户返回或已明确要求继续时，再提出一道不同于原题的复测问题并等待回答。不能把看过页面、点过按钮或示范答案复述记为独立掌握。
